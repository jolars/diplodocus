# Commands

`check`, `extract`, `build`, and `serve` use `./diplodocus.toml` unless given
`--config PATH`. Extraction writes `.diplodocus/documentation.sqlite` beside
that configuration; `extract --output PATH` changes the snapshot destination.
`generate` requires `--input PATH`. `generate`, `build`, and `serve` write to
`./site` unless given `--output PATH`. Relative command-line paths resolve from
the working directory.

For example, extract once and generate from the completed snapshot:

```console
diplodocus extract --output documentation.sqlite
diplodocus generate --input documentation.sqlite --output site
```

The snapshot includes structured documentation, provenance, and local assets.
Generation validates its records and output before publication. A copied
snapshot can be generated without the original source files or language
runtimes. See [portable snapshots](snapshots.md) for compatibility and refresh
behavior.

`serve` listens on `127.0.0.1:8000` by default. Use `--host` and `--port` to
change the address, and `--live-reload` to refresh open pages after a successful
rebuild. A failed rebuild prints diagnostics and keeps serving the last
successful site. Warnings permit a successful exit; errors cause a nonzero exit
status. Output destinations cannot replace declared inputs. The [diagnostics
guide](diagnostics.md) explains reported codes and failed builds.

Start with the [small example](quick-start.md) or see its [workspace
configuration](configuration.md).

**Usage:** `diplodocus <COMMAND>`

## `diplodocus build`

Build a static documentation site

**Usage:** `diplodocus build [OPTIONS]`

### Options

- `--config <PATH>`

    Path to the workspace configuration file

    Default value: `./diplodocus.toml`

- `--output <PATH>`

    Directory in which to write the generated site

    Default value: `./site`

## `diplodocus check`

Check documentation without writing a site

**Usage:** `diplodocus check [OPTIONS]`

### Options

- `--config <PATH>`

    Path to the workspace configuration file

    Default value: `./diplodocus.toml`

## `diplodocus extract`

Extract a portable SQLite documentation snapshot

**Usage:** `diplodocus extract [OPTIONS]`

### Options

- `--config <PATH>`

    Path to the workspace configuration file

    Default value: `./diplodocus.toml`

- `--output <PATH>`

    Snapshot destination (defaults to .diplodocus/documentation.sqlite beside the configuration)

## `diplodocus generate`

Generate a site using only a completed snapshot

**Usage:** `diplodocus generate [OPTIONS] --input <PATH>`

### Options

- `--input <PATH>`

    Completed SQLite documentation snapshot

- `--output <PATH>`

    Directory in which to write the generated site

    Default value: `./site`

- `--format <FORMAT>`

    Output complete site pages or embeddable HTML and Markdown fragments

    Default value: `site`

    Possible values: `site`, `fragments`

- `--url-map <PATH>`

    Public document and asset URL map (requires --format fragments)

## `diplodocus serve`

Build and serve a site, rebuilding when declared inputs change

**Usage:** `diplodocus serve [OPTIONS]`

### Options

- `--config <PATH>`

    Path to the workspace configuration file

    Default value: `./diplodocus.toml`

- `--output <PATH>`

    Directory in which to write the generated site

    Default value: `./site`

- `--host <ADDRESS>`

    Address on which to serve the generated site

    Default value: `127.0.0.1`

- `--port <PORT>`

    Port on which to serve the generated site

    Default value: `8000`

- `--live-reload`

    Refresh open browser pages after successful rebuilds
