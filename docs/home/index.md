# Diplodocus

## Start with a working site

The [getting started tutorial](../guide/quick-start.md) walks through creating
your first site with two Markdown pages. Preview it locally, edit a page, and
build the site for publishing.

To use Diplodocus for your own packages, [install the
CLI](../guide/installation.md) and describe your repositories, packages, and
documentation directories in [project
configuration](../guide/configuration.md).

## Write, check, and publish

Write [pages](../guide/authoring.md) alongside your packages and link
them to the [extracted API references](../guide/extraction.md). Enable
[execution](../guide/execution.md) when you want examples to run as part of the
build.

Choose the order of your pages in [navigation](../guide/navigation.md) and add
your branding in [site appearance](../guide/presentation.md). The
[CLI Reference](../reference/cli.md) covers checking, building, and previewing
your documentation.
