# Diplodocus

## Start with a working site

The [quick start](../guide/quick-start.md) walks through a small project with
Python, R, Julia, and Rust packages. Build its documentation, follow links
between equivalent functions, and edit a guide to see the preview update.

To use Diplodocus for your own packages, [install the
CLI](../guide/installation.md) and describe your repositories, packages, and
documentation directories in [workspace
configuration](../guide/configuration.md).

## Write, check, and publish

Write [authored pages](../guide/authoring.md) alongside your packages and link
them to the [extracted API references](../guide/extraction.md). Enable
[execution](../guide/execution.md) when you want examples to run as part of the
build.

A [portable snapshot](../guide/snapshots.md) stores the collected documentation
and results, so you can generate the site later without the source checkout. The
[command reference](../reference/cli.md) covers checking, building, previewing,
and generating your documentation.
