# Development

This section explains how Diplodocus fits together and how to work on it. Start
with the [design](design.md) for the ideas behind the extraction, snapshot, and
rendering pipeline.

The [contributing guide](../../CONTRIBUTING.md) covers the development
environment, checks, and pull requests. The [browser development
guide](browser.md) explains the preview, browser tests, and screenshot workflow.
The [changelog](../../CHANGELOG.md) records released changes.

For exact commands and configuration fields, use the
[reference](../reference/index.md). The [snapshot
format](../reference/snapshots.md) describes the storage boundary for tools that
consume documentation directly.
