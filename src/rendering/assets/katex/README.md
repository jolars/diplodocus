# KaTeX styles and fonts

KaTeX 0.18.5 matches the upstream version tracked by `katex-rs` 0.3.0.
The stylesheet and fonts come from https://registry.npmjs.org/katex/-/katex-0.18.5.tgz.
Archive SHA-256: `3a37c3713a2cdda03b135f717dd8dcf908d4fddac688b38128c38afa21119ec5`.

KaTeX and its bundled fonts are distributed under the included MIT license.
The renderer embeds these files; building and generating require no downloads.
Equations are rendered natively by `katex-rs`. No browser JavaScript renderer
is shipped.
