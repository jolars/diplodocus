# Tiny Stats

## Compare observations and predictions

Start with the [quick start](getting-started/quick-start.md) to calculate scores
for two sets of numbers. Then work through [comparing
predictions](guides/comparing-predictions.md) to see how individual errors
contribute to the mean squared error.

Different scores answer different questions. The guide to [choosing a
metric](guides/choosing-a-metric.md) compares error magnitude, bias, and R
squared. [Inspecting residuals](guides/inspecting-residuals.md) shows why a
single score cannot tell you everything about a model's predictions.

## Follow a calculation across languages

The Python, R, Julia, and Rust packages expose the same six operations. Choose a
language in the navigation bar to explore its API, then follow **Same API in**
to compare a function with its counterparts.

These packages are small, working examples for Diplodocus. The [guide
overview](overview.md) connects the shared explanations, installation
instructions, and language-specific workflows.
