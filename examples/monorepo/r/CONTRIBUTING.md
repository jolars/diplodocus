# Contributing to Tiny Stats

Tiny Stats is an example in Diplodocus. Report documentation or calculation
problems in the [Diplodocus issue tracker](https://github.com/jolars/diplodocus/issues).

Keep the R, Python, and Julia operations consistent. Add a known-answer case to
the package tests when changing a calculation, and check the shared guides and
equivalent API links.

Read our [code of conduct](CODE_OF_CONDUCT.md) before contributing.
