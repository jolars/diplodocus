# Diplodocus artwork

`diplodocus-logo.svg` is a clean vector redraw of the
[`writing-diplodocus-illustrated.png`](../../docs/design/logo-concepts/writing-diplodocus-illustrated.png)
concept. The book, legs, body, face, spots, and pencil are named SVG objects in
Inkscape layers. It contains no embedded bitmap or font dependency.

`favicon.svg` simplifies the head, pencil, and book for small sizes.
`favicon.ico` contains 16, 32, and 48 pixel versions; `apple-touch-icon.png` is
180 pixels. Edit `favicon.svg` first, then regenerate the raster icons with
Inkscape and ImageMagick.

The SVG files use slate `#202c38`, blue-green `#688b84`, ochre `#a04605`, and
the site's near-white `#fafbf9`.
